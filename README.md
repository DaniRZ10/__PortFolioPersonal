# Portfolio personal — Daniel Ríos Zea

Web personal donde presento mi perfil, experiencia, tecnologías y proyectos.

🔗 **Web:** https://danirz10.github.io/__PortFolioPersonal/

## Tecnologías
- HTML5 semántico y CSS3 puro, sin frameworks ni JavaScript
- Flexbox y CSS Grid para la maquetación
- Diseño responsive (móvil, tablet y escritorio)
- Imágenes optimizadas en WebP e iconos SVG

## Estructura
```
index.html      → contenido de la página
styles.css      → estilos (metodología BEM)
assets/         → imágenes, iconos de tecnologías y CV en PDF
```
